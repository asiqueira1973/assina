# Como contribuir

O código do Assina é aberto, sob a [licença MIT](LICENSE): você pode usar, estudar, adaptar e publicar a sua própria versão (um fork), mantendo o aviso de copyright. O desenvolvimento deste repositório, porém, acontece só do lado da Dab Lab.

## Issues: bem-vindas

Encontrou um bug, ficou com dúvida ou tem uma sugestão? Abra uma [issue](../../issues). Toda issue é lida.

Se o problema for de segurança (por exemplo, acesso a documento de outra pessoa ou um jeito de burlar a verificação), não abra issue pública: escreva para alexandre@dablab.com.br.

## Pull requests: não são aceitos

Pull requests neste repositório não são aceitos e são fechados automaticamente. Se você tem uma ideia de mudança, descreva-a numa issue; se quiser seguir por conta própria, faça um fork.

Obrigado pelo interesse.
