# 8.14 — Data de nascimento do assinante

Pedido do Alexandre (20/11/2026): além do CPF, o remetente pode pedir a data de nascimento.
Decisões dele:
- opção **separada** do CPF ("Pedir data de nascimento"), só para quem assina;
- a data aparece **completa** no manifesto (15/03/1985);
- validação: data real, não futura e de no máximo 120 anos atrás (`NASCIMENTO_IDADE_MAX`). Não barra menor de idade.

## Banco (`20261120130000_as_data_nascimento.sql`)
- `as_signatarios.exigir_nascimento boolean not null default false` (check: só `assinar`).
- `as_signatarios.data_nascimento date` (nulo se não exigido; preenchido pelo próprio signatário).
- `as_fn_substitui_signatarios`: lê `exigir_nascimento` da lista.
- `as_fn_filhos_congelados`: `exigir_nascimento` não muda depois do envio.
- `as_fn_assina`: novo parâmetro `p_data_nascimento date default null`; exigido e ausente,
  futuro ou anterior a 120 anos → `nascimento_invalido`; grava só se exigido.

## Servidor e telas
- `src/lib/birthdate.ts`: `isValidBirthdate("AAAA-MM-DD")` (mesma regra do banco) e formatação.
- Editor: caixa "Pedir data de nascimento" ao lado de "Pedir CPF".
- Folha da assinatura: campo "Data de nascimento" (`type="date"`); "Assinar" desabilitado enquanto inválida.
- Manifesto: linha "Data de nascimento" com a data completa.
- API (`exigir_nascimento` em `signatarios[]`), OpenAPI, MCP (`criar_envelope`) e analytics
  (`nascimento_exigido` em `assina_documento_assinado`).

## Testes
- pgTAP: exigida e ausente / futura / velha demais → `nascimento_invalido`; válida grava; não exigida não grava; congelada depois do envio.
- Vitest: `isValidBirthdate`, manifesto com a data, rota de assinatura recusando e aceitando.
